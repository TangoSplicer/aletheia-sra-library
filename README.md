## 🏛️ Forensic Truth Database
The **Aletheia Standard Reference Artifact (SRA) Library** is the sibling repository to Project Aletheia. It contains high-fidelity hashes of known "clean" software artifacts (UK Banking apps, OS binaries, IoT firmware) to enable **Verification of Method** for ISO 17025 and UK FSR Code v2 compliance.

## 🤝 Vetted Contributions Only
To maintain court integrity, only hashes generated by verified forensic units or software vendors are merged.
